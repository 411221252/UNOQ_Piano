# UNO Q 迷你鋼琴

在電腦瀏覽器點選琴鍵或使用電腦鍵盤演奏鋼琴音色，錄下最多 10 秒的演奏、回放並儲存旋律。

也有「小星星」與「歡樂頌」兩首練習曲：按「示範播放」聽旋律及看目前音符提示，或按「跟我彈」照提示逐音練習。可用速度滑桿調整每分鐘拍數（BPM），再開啟節拍器跟拍。

找出 UNO Q 在區域網路的 IP 位址，在同一網路的電腦瀏覽器開啟 `http://<UNO-Q-IP>:8000`。

## 錄音與儲存

- 按「開始錄音」後演奏，錄音最長 10 秒，時間到會自動停止。
- 「播放錄音」會重播音高與節奏。
- 完成錄音時會自動記住在目前瀏覽器；按「儲存錄音」會下載 JSON 旋律檔，可用「載入錄音」重新載入。
- 使用「載入錄音」可以載入之前下載的旋律檔。
- 練習曲可以調整速度，節拍器會依設定的 BPM 發出提示音。

錄音儲存的是琴鍵演奏事件（音符與時間），不是麥克風收音，因此檔案很小，也能忠實重播演奏。

## 電腦鍵盤

每個琴鍵下方都有對應字母。按住按鍵發聲，放開停止；滑鼠或觸控也可演奏。
